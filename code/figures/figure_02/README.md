# Figure 02

Figure 2 is the final conceptual schematic used in the paper. Unlike the
other figures, it is an authored illustration rather than the output of a
MATLAB data-analysis workflow.

The repository contains the final vector PDF as `output/Figure2.pdf`. It
illustrates:

- how water-surface undulations produce apparent angular residuals in tracked
  flow paths;
- inference of water-surface geometry relative to the planar assumption;
- the standing-wave wavelength and amplitude definitions; and
- correction of the apparent vectors to the streamwise direction.

No external data or software dependencies are required to use the deposited
figure.
